# First Challenge - Residência Instituto de Pesquisas ELDORADO  
### Projeto Miop.IA

## Visão Geral
O projeto **Miop.IA** busca desenvolver uma extensão apoiada em inteligência artificial para estimular o senso crítico do usuário diante de notícias tendenciosas.  
O prazo de execução é de **sete semanas**, com múltiplas frentes de trabalho: levantamento de dados, modelagem, desenvolvimento da extensão e validação com usuários.

## Metodologia de Gestão
O grupo adotou uma **estrutura híbrida**, organizada em quatro *slots* metodológicos:

1. **[Scrumban](ca://s?q=Explique_o_Scrumban)** (Slot A - Coordenação geral)  
   - Combina cadência do Scrum com flexibilidade do Kanban.  
   - Elimina burocracias excessivas e mantém entregas semanais.  
   - Ferramenta de apoio: **JIRA**.

2. **[Design Thinking](ca://s?q=Explique_o_Design_Thinking)**, **Double Diamond** e **MASP** (Slot B - Diagnóstico)  
   - Garantem centralidade no usuário e análise de causa raiz.  
   - Técnicas: diagrama de Ishikawa e 5 Porquês.

3. **[CPMAI](ca://s?q=Explique_o_CPMAI)** + elementos de **CRISP-DM** e **SEMMA** (Slot C - Dados e IA)  
   - Estrutura ágil e ética, com foco em LGPD e fairness.  
   - Uso de datasets públicos (ICMC, LIAR, FakeNewsNet).  
   - Ferramentas: Python (Pandas, NLTK, spaCy, Hugging Face).

4. **[Lean Startup](ca://s?q=Explique_o_Lean_Startup)** + técnicas complementares (Slot D - Validação)  
   - Ciclo construir-medir-aprender.  
   - Métodos: Design Sprint, Mágico de Oz, Shadow Mode, AI TRiSM/Red Teaming, A/B Testing.

---

## Considerações Finais
A metodologia híbrida proposta combina:  
- **Gestão ágil flexível** (Scrumban)  
- **Centralidade no usuário** (Design Thinking)  
- **Rigor técnico em ciência de dados** (CPMAI/CRISP-DM/SEMMA)  
- **Validação contínua** (Lean Startup)  

Essa estrutura cobre de ponta a ponta as **18 guiding constraints** do projeto Miop.IA, garantindo adaptabilidade, ética e impacto real.
